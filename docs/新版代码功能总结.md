## 一、本次新增功能总览

相比旧基线 `d86589b`，队友新增了 **5 大功能模块 + 2 处优化**：

### 1. AD9834 双频率/双相位寄存器支持（全新 API）

旧版只能写入 FREQ0。新版支持完整的双寄存器 API：

```c
ad9834_set_frequency_register_hz(ad9834_frequency_register_1, 2000000u);
ad9834_set_phase_register_degrees(ad9834_phase_register_1, 90u);
ad9834_select_frequency_register(ad9834_frequency_register_1);
ad9834_select_phase_register(ad9834_phase_register_1);
```

- 28 位频率寄存器 × 2（FREQ0/FREQ1）
- 12 位相位寄存器 × 2（PHASE0/PHASE1）
- FSELECT 引脚（PB14）选 FREQ0/FREQ1
- PSELECT 引脚（PD8）选 PHASE0/PHASE1
- 写寄存器和切换引脚分离，支持"先写好备用，再瞬间切换"
- 诊断结构扩展到记录两组寄存器的频率、相位字和当前选择

### 2. ADC 引导的 DDS 中频闭环补偿（核心新功能）

新版不再是"DDS 设一次就完"，而是**5 次闭环修正**：

```
M 按键 -> TIM5 粗测 -> DDS 初始 = fin - 100 kHz
       -> ADC/FFT 测中频 fif
       -> error = fif - 100 kHz
       -> DDS_new = DDS_old + error
       -> 成功 5 次后进入 holding 状态
```

- 状态机：`waiting -> coarse -> compensating -> holding`
- 粗调不计入 5 次补偿
- 只消费**新的、有效的** FFT 帧（用 sequence 序号去重）
- 每次成功 DDS 更新后 `measurement_fft_resynchronize()` 重同步 FFT 窗口，避免调整前后的样本混入
- 5 次后保持最终 DDS 频率，不再自动改变
- 再次按 `M` 清零重新开始

### 3. HMI 立即测量命令（新交互）

串口屏现在支持两种命令：

| 命令字节 | 功能 |
|----------|------|
| `0`～`5`（ASCII） | 选择 VGA 档位 |
| `M` / `m`（ASCII 0x4D） | **立即触发一次 TIM5 粗测 + 5 次 ADC 闭环补偿** |

USART1 接收使用单字节中断，主循环消费命令。`M` 命令同时调用：
- `frequency_measure_request_now()`
- `dds_control_request_compensation()`

### 4. VGA 实测电压模型（优化）

旧版直接用 DAC 指令电压算增益。新版区分 **DAC 指令电压** 和 **PA4 实测电压**：

| 档位 | DAC 指令电压 | PA4 实测电压 | 默认 VG | 默认理论增益 AV |
|------|------|------|------|------|
| 0 | 0.00 | 0.023 | -0.986061 | 0.013939 |
| 1 | 0.66 | 0.683 | -0.586061 | 0.413939 |
| 2 | 1.32 | 1.362 | -0.174545 | 0.825455 |
| 3 | 1.98 | 2.040 | 0.236364 | 1.236364 |
| 4 | 2.64 | 2.720 | 0.648485 | 1.648485 |
| 5 | 3.30 | 3.370 | 1.042424 | 2.042424 |

公式：
```
VG = (20/33) × V_PA4_实测 - 1
AV = (1 + VG) × Rf / RG
VOUT = (+VIN - -VIN) × AV
```

实测电压以宏形式独立存放，PA4 重新标定后只改宏不改 DAC 码。

### 5. 频率/幅度换算集中到 measurement_conversion 模块（新）

旧版校准公式散落在 HMI 里。新版统一到 `measurement_conversion.c`：

- **频率换算**：`DDS 频率 + ADC 中频`（两者均有效时），否则回退 TIM5 粗测
- **幅度换算**：`ADC Vpp / 当前 VGA 理论增益`（增益有效时），否则保留 ADC Vpp

后续整机频响拟合只改这一个模块，不碰 HMI。

### 6. 频率校准分段公式（优化）

FFT 原始频率做分段反向修正：

```text
f_raw ≤ 40000 Hz: f_cal = 1.0000193004 × f_raw + 0.24140466
f_raw >  40000 Hz: f_cal = 1.0000414617 × f_raw + 0.3261338
```

校准结果分别写入 `peak_frequency_hz` 和 `secondary_peak_frequency_hz`，raw 字段保留供调试。

## 三、新功能带来的变化对比

### 3.1 操作流程变化

**旧版**：
1. 上电 -> DDS 按 TIM5 粗测设一次
2. HMI 显示各种频率/幅度
3. 手动按 0~5 选 VGA 档位

**新版**：
1. 上电 -> DDS 按 TIM5 粗测设一次
2. HMI 显示各种频率/幅度
3. 手动按 0~5 选 VGA 档位
4. **按 M 触发 5 次闭环补偿** -> DDS 逐步逼近使中频 = 100 kHz
5. 5 次后 holding 状态，DDS 固定在最终频率
6. 再按 M 可以重新追频

### 3.2 精度变化

- 旧版：DDS 精度 = TIM5 粗测精度（1~30 MHz 范围内约 ±10 kHz）
- 新版：经过 5 次闭环后，DDS 精度 = ADC/FFT 中频测量精度（理论上可达 ±1 kHz 以内）

### 3.3 调试变量变化

新版新增可观察的诊断变量：
- `dds_control_diagnostics.compensation_count` - 本轮已成功完成的 ADC 闭环补偿次数
- `dds_control_diagnostics.compensation_request_count` - 收到的立即补偿请求总数
- `dds_control_diagnostics.adc_frequency_hz` - 最近一次用于补偿的校准后 ADC 中频
- `dds_control_diagnostics.frequency_error_hz` - 最近一次 ADC 中频相对 100 kHz 的误差
- `dds_control_diagnostics.last_result_sequence` - 最近一次已消费的 FFT 结果序号
- `dds_control_diagnostics.state` - 当前状态（waiting/test/coarse/compensating/holding/error）
- `ad9834_diagnostics.frequency_hz[2]` - FREQ0 和 FREQ1 最近成功写入的频率
- `ad9834_diagnostics.phase_degrees[2]` - PHASE0 和 PHASE1 最近成功写入的角度

## 四、已知限制

1. PA0 输入必须经过可靠整形并满足 MCU GPIO 电平范围（0~3.3V）
2. PC4、PB1 不得超过 ADC 模拟输入范围；8.5 Cycles 采样时间要求模拟前端具备足够驱动能力
3. FFT、ADC 电压、DAC 实测电压和整机幅频关系均可能随时钟、VDDA、温度和模拟前端变化，需要重新实板标定
4. 当前 VGA 增益使用 PA4 实测控制电压和理论 Rf/RG 模型，**不能替代 VGA 器件的整机增益标定**（Rf/RG 当前默认 1.0，需换实际阻值）
5. USART1 为 9600 bit/s，刷新被安排在 FFT 显示空档；增加控件或频谱发送量时需重新评估时序
6. DDS 输出限制为 1~30 MHz，MCLK 75 MHz
7. 5 次补偿上限固定，无法从 HMI 动态调整

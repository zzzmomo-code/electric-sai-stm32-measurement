# 120 kHz FFT 测量与显示范围设计

## 目标

将双通道测量的主峰搜索上限和串口屏 64 点压缩频谱上限由 100 kHz 统一扩展到 120 kHz，不改变 600 kSPS 同步采样率、65536 点 FFT、ADC/DMA/TIM2 配置和诊断结构体字段。

## 设计

- 沿用统一常量 `MEASUREMENT_FFT_SPECTRUM_MAX_HZ`，将其值由 `100000.0f` 改为 `120000.0f`。
- 主峰搜索继续使用该常量计算最大搜索频点，因此搜索范围变为 1 Hz 至 120 kHz。
- HMI 频谱继续使用同一常量压缩为 64 点，因此显示范围变为 0 至 120 kHz，每点覆盖 1875 Hz。
- FFT 频点间隔保持 `600000 / 65536`，约为 9.155273 Hz；主频插值算法不变。
- THD 仍以 300 kHz Nyquist 为边界自动截断越界谐波。120 kHz 输入可统计二次谐波 240 kHz，三次及以上谐波越界，因此高频端 THD 和波形分类能力有限。
- 不修改公共接口、诊断结构体、采样缓存、FFT工作区及串口协议。

## 验证

- 先增加契约测试，要求上限常量为 `120000.0f`，并确认测试在生产代码修改前失败。
- 修改常量、中文注释和 README 后重新运行全部主机测试。
- 执行 STM32CubeIDE Debug Clean Build，要求 0 error；硬件验证由用户烧录完成。
- 板上输入 120 kHz 同频正弦波时，预期主峰约位于频点 13107，两个通道频率接近 120 kHz，且 ADC backlog、overflow 和 error 计数保持为零。

## 不在范围内

- 不扩展到 200 kHz。
- 不改变 64 点频谱点数。
- 不修改 ADC、TIM2、DMA、GPIO 或 `.ioc`。
- 不承诺 120 kHz 下完整的三次及以上谐波、THD或非正弦波分类。

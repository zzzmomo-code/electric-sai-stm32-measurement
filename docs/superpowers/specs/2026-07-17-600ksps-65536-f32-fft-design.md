# 600 kSPS 双 ADC 与 65536 点 F32 FFT 设计

## 目标

在 STM32H743VIT6 上将 ADC1、ADC2 双路同步采样率提升为每通道 600 kSPS。每帧保存 65536 个同步样本对，停止采样后依次完成两通道自定义单精度浮点实数 FFT、测量结果发布和串口屏刷新。

保留 `measurement_fft_diagnostics_t` 的全部现有字段、字段名和对外接口。串口屏 `t_voltage`、`t_voltage2`、`t_amp`、`t_amp2` 继续使用整帧测量结果，不读取 `adc_dual_stats_t` 的累计统计字段。

## 采样配置

- MCU：STM32H743VIT6。
- ADC 模式：ADC1/ADC2 Dual Regular Simultaneous。
- 每通道采样率：600000 sample/s。
- TIM2 输入时钟：240 MHz。
- TIM2 Prescaler：0。
- TIM2 Counter Period：399。
- TIM2 TRGO：Update Event。
- ADC1 继续由 TIM2 TRGO 上升沿触发；ADC2 作为双模式从 ADC。
- ADC DMA 继续使用 32 位 packed word，低 16 位为 ADC1，高 16 位为 ADC2。
- DMA 继续使用循环模式、Word/Word、Memory Increment 和 Very High Priority。
- 当前 `.ioc` 的 ADC kernel clock 为 64 MHz，采样时间为 8.5 cycles；600 kHz 触发周期为 1.667 us，满足当前 16 位转换时序。

一帧采集时间为 109.227 ms，FFT 频点间隔约为 9.155 Hz，奈奎斯特频率为 300 kHz。100 kHz 基波每周期有 6 个样本；20 Hz 每帧约有 2.18 个周期，因此低频幅度和 THD 需要硬件实测评估。

## 数据结构与内存

新增同步样本类型：

```c
typedef struct
{
    uint16_t ch1_code;
    uint16_t ch2_code;
} adc_dual_sample_pair_t;
```

保存 65536 个样本对，共 256 KiB。样本帧放入 RAM_D2，并保持适合 Cortex-M7 Cache 维护的 32 字节对齐。

FFT 使用一块可复用的 65536 个 `float32_t` 原地工作区，共 256 KiB，放入 RAM_D1。CH1 和 CH2 依次复用该工作区。DMA 小循环缓冲继续独立存在，只负责接收 packed word；主循环领取半满或满标志后完成 Cache invalidate、拆包和样本对写入。

不保存完整 Hann 窗表和完整旋转因子表。Hann 系数在装载通道数据时递推生成；FFT 每一级的旋转因子从该级初值递推生成，以控制 RAM 占用。

`adc_dual_stats_t` 继续保存 DMA 次数、错误、积压、累计样本数、最值和运行状态，不扩展为 65536 项数组。

## FFT 算法

CMSIS-DSP 的 `arm_rfft_fast_f32()` 不支持 65536 点，因此实现自定义 65536 点 F32 实数 FFT：

1. 从一个通道的 65536 个原始码计算整帧最小值、最大值、平均值和去直流 RMS。
2. 去除整帧实际平均值并施加 Hann 窗。
3. 将偶数样本和奇数样本打包为 32768 个复数数值。
4. 对 32768 点复数序列执行原地 Radix-2 F32 FFT，包括位反转和逐级蝶形运算。
5. 执行实数 FFT 后处理，得到 0 至 300 kHz 的 packed 频谱。
6. 提取峰值、亚频点插值、幅度、谐波、THD、波形分类、压缩频谱和相位所需复数特征。
7. 保存 CH1 的必要特征后复用工作区处理 CH2，并在共同频点计算 CH2 相对 CH1 的相位差。

FFT 运行时由 DWT 周期计数器统计双通道完整处理时间。所有中间值必须检查有限性，禁止向结果层发布 NaN、无穷或越界频率。

## 测量与串口屏数据流

`t_voltage` 和 `t_voltage2` 显示各通道 65536 点整帧平均电压。它们只依赖原始样本和 `measurement_fft_calibration_t`。

`t_amp` 和 `t_amp2` 显示 Vpp：

- 正弦波、方波和三角波根据整帧去直流 RMS 与波形类型换算；
- 未知波形回退到整帧最大码与最小码之差；
- 已校准时使用 `volts_per_code` 和 `offset_v`；
- 未校准时使用标称 `3.3 V / 65535` 并保持估算标记。

HMI 只读取 `measurement_result_t` 快照，不读取 DMA 缓冲、样本帧或 `adc_dual_stats_t`。

## 诊断兼容性

`measurement_fft_diagnostics_t` 的现有字段全部保留：

- `init_status` 表示自定义 FFT 初始化与自检状态；
- `window_count` 表示收齐的 65536 点窗口数量；
- `last_fft_cycles` 表示最近一次双通道完整 FFT 与频谱分析周期数；
- `raw_sample_rate_hz` 和 `effective_sample_rate_hz` 均为 600000；
- `bin_width_hz` 为约 9.155；
- `decimation_factor` 保持 1；
- 两路帧最小码、最大码、平均码继续来自当前完整帧；
- 两路 DC、RMS、Vpp、频率、THD、谐波、波形、相位、削顶、校准、质量和有效状态继续更新；
- `capture_resync_count` 在 DMA 顺序不可信或帧被主动放弃时递增。

允许增加自定义 FFT 内部诊断字段，但不删除或重命名现有字段。

## 状态机与错误处理

- DMA 半满回调、满回调和 ADC 错误回调各自只设置一个对应标志变量。
- 主循环处理标志、Cache、拆包、样本写入及标志清除。
- 收满 65536 点后 `measurement_fft_sampling_required()` 返回 0，`adc_dual_process()` 停止 TIM2。
- FFT、结果发布和串口屏刷新完成后清空帧状态，再允许 TIM2 启动下一帧。
- 同时收到前后半区标志、DMA 次序异常或 ADC overrun 时，放弃当前帧并重新同步，禁止拼接不连续数据。
- 削顶、信号过小、通道频率不匹配、相位无效或 FFT 数值异常时沿用现有质量和 fault 字段。
- 对 100 kHz 基波，二次谐波 200 kHz可参与 THD；三次谐波位于 300 kHz 奈奎斯特边界，必须排除。

## 验证

离线测试至少覆盖：

- 65536 点 FFT 对单频、双频、DC、正弦、方波和三角波的频率与幅度结果；
- 20 Hz、100 kHz 和频点非整数周期信号；
- 两通道 0、正负 90 和 180 度相位差；
- Hann 窗幅值补偿、亚频点插值与 THD 谐波边界；
- NaN、零信号、削顶、DMA 重同步和帧暂停/恢复；
- 所有原有 `measurement_fft_diagnostics_t` 字段继续更新；
- `t_voltage/t_voltage2` 与 `t_amp/t_amp2` 不访问 `adc_dual_stats_t`。

完成代码后执行源码契约测试、静态检查和 STM32CubeIDE Clean Build。上板验证包括真实采样率、DMA 稳定性、FFT 周期、20 Hz 与 100 kHz 测量误差、串口屏刷新以及长期运行稳定性。

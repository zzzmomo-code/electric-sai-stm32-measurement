# 淘晶驰 HMI 非覆盖式视觉改版设计

日期：2026-07-29

目标设备：800×480 淘晶驰串口屏

源工程：`fpga1.HMI`

新版工程：`fpga1_codex_ui_v1.HMI`

## 1. 目标

在不改变现有 STM32 通信接口、曲线数量、曲线尺寸和按键功能的前提下，制作一份更简洁、清晰、适合比赛现场读取的 HMI。

本次只调整页面的排版、字号、颜色和视觉层级，不修改：

- STM32 固件；
- `.ioc` 配置；
- 串口通信协议；
- 控件对象名；
- 已有按键指令；
- 波形和频谱的数据点数及显示逻辑。

## 2. 非覆盖式编辑规则

`fpga1.HMI` 作为已验证基线，只读保留，不在其上直接编辑。

实施时采用以下步骤：

1. 关闭 USART HMI 编辑器中占用 `fpga1.HMI` 的窗口；
2. 计算并记录 `fpga1.HMI` 的 SHA-256；
3. 复制为 `fpga1_codex_ui_v1.HMI`；
4. 只打开和编辑新文件；
5. 完成后再次计算 `fpga1.HMI` 的 SHA-256，确认与编辑前一致；
6. 新旧 HMI 同时保留，实板不满意时可立即恢复原版。

HMI 是专有二进制格式，不能依赖普通文本 diff 审查，因此同时保留：

- 源文件前后 SHA-256；
- 新版页面截图；
- 控件名和事件检查表；
- USART HMI 编译结果。

## 3. 功能接口冻结

### 3.1 控件对象名

下列对象名必须保持不变，因为 STM32 固件直接通过名称写属性或添加曲线数据。

| 类型 | 对象名 | 用途 |
|---|---|---|
| 文本 | `t_vpp` | 峰峰值 |
| 文本 | `t_vrms` | 真有效值 |
| 文本 | `t_freq` | 基频 |
| 文本 | `t_status` | FPGA/测量状态 |
| 文本 | `t_comp1` | 第一频率分量 |
| 文本 | `t_comp2` | 第二频率分量 |
| 文本 | `t_comp3` | 第三频率分量 |
| 按钮 | `b_t1` | 显示一周期 |
| 按钮 | `b_t3` | 显示三周期 |
| 曲线 | `s_t1` | 一周期时域波形 |
| 曲线 | `s_t3` | 三周期时域波形 |
| 曲线 | `s_spec` | 频谱 |

### 3.2 按键事件

- `b_t1` 按下事件保持发送：`printh A5 01 5A`
- `b_t3` 按下事件保持发送：`printh A5 02 5A`
- 保留两个新增按钮位置，初版按钮文字统一为“预留”；
- 两个预留按钮不得勾选“发送键值”，不得配置 `printh`，不得产生 UART 数据。

预留按钮暂不命名为业务功能，避免页面先于固件确定错误接口。实现时使用不会与现有对象冲突的名称，例如 `b_rsv1`、`b_rsv2`。

### 3.3 曲线关系

- `s_t1` 与 `s_t3` 在左侧完全重叠，占用同一个时域图区域；
- STM32 继续使用 `vis` 控制一周期与三周期曲线的可见性；
- `s_spec` 独立位于右侧，始终与时域图分开；
- 三个曲线控件均保持单通道配置和现有通道编号；
- 每个曲线控件宽度固定为 350 像素，高度固定为 210 像素；
- STM32 仍向每张图发送 350 个显示点。

### 3.4 页面与串口设置

- 保持单页面 `page0`；
- 保持当前串口波特率和通信模式；
- 保持上电初始化脚本、曲线初始可见性和 `WAIT FPGA` 状态初始化；
- 不新增页面跳转，不新增开始测量按钮，不恢复旧版频谱切换按钮；
- 不修改现有 `bkcmd`、`recmod`、背光和系统变量设置。

## 4. 最终视觉方案

### 4.1 风格

采用“明亮仪表”风格：

- 页面底色：浅灰白；
- 信息卡片：白色；
- 主色：克制的深蓝色；
- 状态正常：绿色；
- 波形：青色；
- 频谱：琥珀色；
- 图表底色：深色；
- 网格线降低亮度，避免抢过数据曲线。

不使用大面积渐变、发光、复杂阴影、装饰性图片或过度圆角。优先使用串口屏原生矩形、文本、按钮和曲线控件，降低资源占用和兼容风险。

### 4.2 可读性

- 页面标题约 20 像素；
- 一级数据值约 20 像素；
- 数据标签约 14～16 像素；
- 分量文本约 14～16 像素；
- 图表标题约 18 像素；
- 按钮文字约 17～18 像素；
- 坐标标签约 14～16 像素。

实现时优先复用原 HMI 已有 GBK 字库，选择最接近上述尺寸的现有字体。只有现有字体无法满足时才新增字库。

STM32 当前分量字符串可能为 `H1 12.345 kHz 1.650 V` 一类较长文本。分量值区域必须单行完整显示，不允许自动换行；在模拟器中使用最长预期字符串检查截断。

### 4.3 800×480 布局

以下坐标为页面内容区目标坐标。曲线尺寸是硬约束；其他装饰和文本位置允许在 USART HMI 编辑器中做不超过数像素的对齐修正。

#### 顶部栏

- 外框：`x=24, y=10, w=752, h=40`
- 标题左对齐：“周期信号测量分析装置”
- 状态右对齐：显示 `t_status`

状态文本不再占用一张与数据等大的卡片，放入顶部栏右侧，减少拥挤。

#### 第一行主要参数

| 内容 | 目标区域 |
|---|---|
| 峰峰值 `t_vpp` | `x=24, y=60, w=170, h=50` |
| 真有效值 `t_vrms` | `x=204, y=60, w=170, h=50` |
| 基频 `t_freq` | `x=384, y=60, w=170, h=50` |

每个区域采用“小标签 + 大数值”的层级，不把单位拆成独立控件。

#### 第二行频率分量

| 内容 | 目标区域 |
|---|---|
| 第一分量 `t_comp1` | `x=24, y=120, w=170, h=46` |
| 第二分量 `t_comp2` | `x=204, y=120, w=170, h=46` |
| 第三分量 `t_comp3` | `x=384, y=120, w=170, h=46` |

#### 右侧四按钮区

| 按钮 | 目标区域 | 行为 |
|---|---|---|
| `b_t1` | `x=570, y=60, w=96, h=44` | 显示一周期 |
| `b_t3` | `x=680, y=60, w=96, h=44` | 显示三周期 |
| `b_rsv1` | `x=570, y=120, w=96, h=44` | 预留，无事件 |
| `b_rsv2` | `x=680, y=120, w=96, h=44` | 预留，无事件 |

按钮保持中等尺寸，兼顾触摸可靠性与页面比例；不做横跨页面的大按钮。

#### 图表区

- 图表标题基线：约 `y=179`
- 图表控件顶部：`y=209`
- 左侧时域图：350×210
- 右侧频谱图：350×210
- 左图中 `s_t1` 与 `s_t3` 完全同坐标、同尺寸；
- 右图只放 `s_spec`；
- 坐标百分比标签放在曲线控件外侧，不能侵占 350×210 数据区。

图表最终横向间距根据坐标标签宽度微调，但两张图的数据区域不得缩小。

## 5. 实施方法

1. 复制原 HMI 并确认源文件哈希；
2. 在新版 HMI 中先锁定现有控件对象名和事件；
3. 移动和调整文本、按钮、曲线控件；
4. 添加两个无事件的预留按钮；
5. 调整颜色、字号和对齐；
6. 检查控件层级，保证 `s_t1` 与 `s_t3` 重叠切换时不会被静态装饰遮挡；
7. 在 USART HMI 中编译；
8. 使用模拟器和现有 STM32 指令格式进行功能回归；
9. 生成新版截图和检查记录；
10. 用户确认后再下载到实屏，原 HMI 始终保留。

# 600 kSPS Dual ADC and 65536-Point F32 FFT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 STM32H743VIT6 上以每通道 600 kSPS 保存 65536 个双 ADC 同步样本对，并使用自定义 F32 实数 FFT 保留全部现有测量、诊断和串口屏功能。

**Architecture:** ADC1/ADC2 继续使用 32 位 dual packed DMA，小 DMA 循环缓冲由主循环拆包到 RAM_D2 的 65536 点样本对帧。帧满后停止 TIM2，CH1/CH2 依次复用 RAM_D1 的 256 KiB F32 工作区执行偶奇打包、32768 点原地复数 FFT 和实数后处理，再发布现有结果与诊断快照。

**Tech Stack:** STM32H743VIT6、STM32CubeIDE 1.19.0、STM32Cube FW_H7 V1.12.1、HAL ADC/DMA/TIM/UART、C11、Cortex-M7 FPU/DWT、Python unittest/NumPy 离线模型。

```python
import unittest
import numpy as np

FS = 600_000.0
N = 65_536


class FftF3265536ModelTest(unittest.TestCase):
    def analyze(self, signal):
        centered = signal - np.mean(signal)
        spectrum = np.fft.rfft(centered * np.hanning(N))
        power = np.abs(spectrum) ** 2
        peak = int(np.argmax(power[1:])) + 1
        return peak * FS / N, spectrum, peak

    def test_100khz_frequency(self):
        t = np.arange(N) / FS
        frequency, _, _ = self.analyze(np.sin(2.0 * np.pi * 100_000.0 * t))
        self.assertLess(abs(frequency - 100_000.0), FS / N)

    def test_phase_90_degrees(self):
        t = np.arange(N) / FS
        _, a, peak = self.analyze(np.sin(2.0 * np.pi * 10_000.0 * t))
        _, b, _ = self.analyze(np.sin(2.0 * np.pi * 10_000.0 * t + np.pi / 2.0))
        phase = np.degrees(np.angle(b[peak]) - np.angle(a[peak]))
        phase = (phase + 180.0) % 360.0 - 180.0
        self.assertLess(abs(phase - 90.0), 1.0)

    def test_20hz_has_finite_result(self):
        t = np.arange(N) / FS
        frequency, spectrum, _ = self.analyze(np.sin(2.0 * np.pi * 20.0 * t))
        self.assertTrue(np.isfinite(frequency))
        self.assertTrue(np.all(np.isfinite(spectrum)))
```

### Task 3: Implement the Standalone F32 FFT Engine

**Files:**
- Create: `Core/User/fft_f32_65536.h`

- Modify: `Core/User/system.h`
- Test: `tests/test_fft_f32_65536_model.py`

**Interfaces:**
- Consumes: 65536 `uint16_t` samples selected from sample-pair storage and their mean.
- Produces: `fft_f32_65536_status_t fft_f32_65536_forward(const uint16_t *samples, uint32_t stride, float32_t mean_code, float32_t *packed_spectrum)`.

- [ ] **Step 1: Define the public interface**

```c
typedef enum
{
    FFT_F32_65536_STATUS_OK = 0,
    FFT_F32_65536_STATUS_INVALID_ARGUMENT,
    FFT_F32_65536_STATUS_NONFINITE
} fft_f32_65536_status_t;

fft_f32_65536_status_t fft_f32_65536_forward(
    const uint16_t *samples,
    uint32_t stride,
    float32_t mean_code,
    float32_t *packed_spectrum);
```

- [ ] **Step 2: Implement deterministic packing and Hann generation**

For sample index `n`, compute:

```c
phase = (2.0f * PI * (float32_t)n) / 65535.0f;
window = 0.5f - 0.5f * cosf(phase);
value = ((float32_t)samples[n * stride] - mean_code) * window;
```

Pack `value[2*k]` as real and `value[2*k+1]` as imaginary for the 32768-point complex transform. Use a trigonometric recurrence for subsequent Hann points and periodically renormalize the recurrence every 1024 samples.

- [ ] **Step 3: Implement in-place radix-2 complex FFT**

Use 15 stages for 32768 complex points. Perform bit reversal first. For each stage, calculate one stage root:

```c
angle = -2.0f * PI / (float32_t)butterfly_span;
root_real = cosf(angle);
root_imag = sinf(angle);
```

Advance the per-column twiddle by complex multiplication, and renormalize every 256 columns. Reject nonfinite values and return `FFT_F32_65536_STATUS_NONFINITE`.

- [ ] **Step 4: Implement real-FFT postprocessing**

For `k = 1..32767`, combine `Z[k]` and conjugate `Z[32768-k]` using the standard even/odd real FFT identity. Store packed output as CMSIS-style real spectrum:

```text
packed[0] = Re(X[0])
packed[1] = Re(X[32768])
packed[2*k] = Re(X[k])
packed[2*k+1] = Im(X[k])
```

Handle DC and Nyquist bins separately and preserve pairs until both symmetric inputs have been read.

- [ ] **Step 5: Add a host-testable reference build**

Expose only pure C helpers under `#if defined(FFT_F32_65536_HOST_TEST)` so a host harness can compare packed bins with NumPy for N=65536. Do not add HAL dependencies to this module.

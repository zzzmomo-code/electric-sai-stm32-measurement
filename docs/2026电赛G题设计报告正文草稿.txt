题目：周期信号测量分析装置

摘 要
本系统面向周期信号的频率、幅值、有效值、频谱及主要谐波分量测量与可视化需求，采用“模拟前端调理—高速模数转换与FPGA处理—STM32H743显示控制—串口触摸屏”的分层结构。模拟前端完成输入信号的衰减、放大和抗混叠滤波；FPGA完成采样、数字滤波、FFT及测量参数提取；STM32H743通过带CRC校验的SPI链路读取FPGA测量帧，完成帧完整性校验、标量校准、波形压缩和人机交互；串口屏显示峰峰值、真有效值、基频、前三个有效分量、时域波形和频谱。系统在通信层设置帧序号、长度、CRC和确认机制，在显示层采用“三帧稳定锁存、按键触发重画”的策略，使数据更新可靠且波形不闪烁。软件合同测试已覆盖协议、数据解析、波形转换、校准和显示状态机；整机精度、长期稳定性及题目规定指标仍需按统一测试表完成实测验证。

关键词：周期信号测量；FPGA；STM32H743；FFT；SPI；串口触摸屏；抗混叠

1 方案论证与总体设计

1.1 方案比较
方案一为仅用单片机完成高速采样、频谱分析和显示。该方案软硬件较简单，但高采样率下FFT计算和显示传输争用处理器资源，难以同时保证实时性与显示响应。

方案二为FPGA完成采样与计算，STM32只完成显示。其速度优势明显，但若FPGA直接输出屏幕命令，则测量算法、界面分辨率和屏幕型号彼此耦合，后续修改困难。

本设计采用方案三：FPGA负责数据密集型的ADC采样、数字滤波、FFT和参数测量；STM32H743负责数据可信性校验、工程量换算、曲线压缩、触摸按键和屏幕命令。该分工将测量与显示解耦，既发挥FPGA并行处理优势，又便于修改界面和校准参数，因此选用该方案。

1.2 系统总体方案
建议在正式排版中将下列文字绘制为图1系统总体框图：

被测周期信号 → 输入保护/1/5衰减 → 可编程或固定增益放大 → 低通抗混叠滤波 → AD9226及采样时钟 → FPGA（采集、数字滤波、FFT、频率/幅值/有效值/谐波计算） → SPI+DATA_READY → STM32H743（CRC校验、校准、350点重采样、显示调度） → USART1 → 淘晶驰串口触摸屏。

其中，SPI采用主从方式：STM32为主机，FPGA为从机；DATA_READY指示一帧完整快照已经准备好。STM32读取无误后发送ACK，FPGA才释放该快照，避免读帧期间被新数据覆盖。

2 理论分析与计算

2.1 前端放大与抗混叠设计
AD9226为12位ADC。若前端含1/5衰减、且5 mVpp的小信号直接送入ADC，则有效量化码数不足，量化噪声和后级计算误差会显著增大。因此前端先对小信号实施适当放大，再送入ADC。设前端总电压增益为Av，则ADC输入峰峰值为

VADC,pp = Vin,pp × Av。

增益设计必须同时满足小信号分辨率和大信号不饱和两项约束，即VADC,pp应落在ADC允许满量程范围内。正式报告应根据ADC满量程、衰减网络和实际增益档位补入Av及最大、最小输入的计算结果。

采样系统须在ADC前抑制奈奎斯特频率以上的干扰。以50 MSPS总采样、四路复用的设计讨论为例，单通道等效采样率为12.5 MSPS，奈奎斯特频率为6.25 MHz。若12.6 MHz干扰未被充分衰减，可能混叠为10 kHz，后级无法从数字数据中区分其与真实10 kHz信号。因此抗混叠滤波必须在采样前完成。结合本装置主要测量频段为500 kHz以下，为兼顾通带平坦度、低幅度信号信噪比和实现难度，前端低通截止频率暂定约1.3 MHz；最终截止频率应由实际电阻、电容和实测幅频曲线复核后填写。

前期曾考虑OPA847作20倍放大。TI资料表明其电压增益+20 V/V时针对平坦响应优化，最小稳定增益为+12 V/V，典型增益带宽积为3.9 GHz、在规定闭环增益条件下的典型带宽为600 MHz。因此“数据手册允许20倍增益”并不等价于整块实际电路在目标频段一定平坦：电源去耦、寄生参数、PCB走线、源/负载阻抗和滤波网络都会改变闭环响应。实测中，原OPA847方案在500 kHz处幅度约为10 kHz处的0.8，非线性较大，不利于仅靠查表校准修正，故改用OPA690承担放大和滤波功能。放大器及十阶通用滤波器布置在同一预制板上，可缩短高阻和高增益节点连线，降低级间耦合与外界噪声引入。此处应配“图2 前端放大与十阶滤波电路图”和“图3 实测幅频响应曲线”。

2.2 频谱与测量参数计算
FPGA对采样数据进行4096点FFT。FFT采样率为1.5625 MSPS，频率分辨率为

Δf = fs/N = 1 562 500/4096 = 381.4697 Hz。

FPGA向STM32输出0至1311号频点，频谱幅值单位为10 μVpeak/LSB；时域数据采样率为12.5 MSPS，单位为10 μV/LSB。峰峰值和真有效值由FPGA在同一测量窗内计算并作为帧头字段输出；基频及最多三个有效分量同时给出频率、峰值幅度和谐波次序。显示一周期时，STM32依据

Ns = fs,time / f0

计算每周期样点数，在时域缓存中寻找近均值上升穿越点，截取一周期模板；显示三周期时重复该模板三次。随后以Q16.16线性插值统一压缩成350点，从而避免直接按time_count/3截取造成的周期不完整问题。

2.3 通信及时延分析
完整帧长度为

L = 128 + 2×time_count + 2×spectrum_count + 2，

其中spectrum_count=1312，time_count为75至3750，因此帧长范围为2904至10254字节。SPI协议采用Mode 0、8位MSB优先，所有多字节字段采用小端。冻结协议的目标SCK为20 MHz，最大帧的纯时钟传输时间约为10254×8/20 MHz=4.10 ms；当前联调配置为625 kHz，最大帧传输约131 ms，不能代表最终20 MHz性能。串口屏波形每条为350个点，512000 baud下最坏纯线缆发送约151 ms，仍低于题目“按键后2 s内显示”的时间约束；最终应以整机秒表或逻辑分析仪实测为准。

3 硬件电路设计

3.1 模拟前端
模拟前端由输入保护、1/5衰减、放大、低通滤波和ADC驱动组成。衰减网络扩展大信号输入范围；放大级提高小信号利用的ADC有效码数；低通网络在采样前抑制带外噪声及其混叠。报告排版时应放入原理图，并在图中标明：输入保护器件型号、衰减电阻值、OPA690的反馈/增益电阻、十阶滤波器各级R/C值、截止频率计算式、ADC参考电压、模拟/数字电源和地的处理方式。上述元件实值与原理图本次未提供，不能以文字推测补写。

3.2 FPGA、STM32与屏幕接口
FPGA与STM32H743使用SPI3和1根就绪线连接：PC10为SCK，PC11为MISO，PC12为MOSI，PA15为低有效软件片选FPGA_CS_N，PD1为FPGA_DATA_READY；三者共地且逻辑电平为3.3 V。串口屏接USART1：PA9为TX、PA10为RX，通信参数为512000 baud、8N1。SPI3当前调试速率625 kHz，协议目标20 MHz；二者均为Mode 0。H743的DMA缓冲区静态分配、32字节对齐，并在DMA与CPU交换前进行D-Cache维护，避免缓存不一致导致偶发错帧。

4 软件设计

4.1 FPGA软件/逻辑功能
FPGA完成ADC采集、数字低通、FFT、峰峰值、真有效值、基频和谐波分量计算，并将结果封装为完整测量快照。每帧具有128字节帧头、时域数组、频谱数组和CRC16。帧头含采样率、点数、幅值比例、测量结果、有效标志和帧序号。FPGA在DATA_READY为高期间保持快照不可修改，只有收到序号和CRC均正确的ACK才释放帧，从源头避免“读到半帧”。FPGA内部算法的窗函数、峰值插值、谐波判定阈值及ADC实际连接应由FPGA组补充后写入正式报告。

4.2 STM32软件流程
建议绘制图4软件主流程图：上电初始化 → 检查DATA_READY → 读取状态帧 → 校验状态CRC/长度/序号 → DMA读取完整测量帧 → 校验帧头、长度和CRC → 合法则ACK并发布快照，非法则最多重读3次且不ACK → 工程量换算与350点曲线生成 → 三帧稳定判断 → 发送文字、频谱及按键指定的波形。

CRC采用CRC-16/CCITT-FALSE，参数为poly=0x1021、init=0xFFFF、无反射、xorout=0x0000，标准字符串“123456789”的校验值为0x29B1。协议同时检查帧头魔数“G26F”、版本、长度、保留字段、分量有效位和帧序号；CRC或格式错误不发送ACK，防止错误数据污染显示。

标量校准独立于通信和波形缓存。当前接口以6400 raw/mV进行电压码值换算，频率字段由mHz换算为Hz；后续将多点实测数据拟合后，仅需替换校准模块的系数。屏幕上“已校准/未校准”按键只切换标量文字的显示方式，不触发重新采样、FFT或曲线重画，便于继续打表。

4.3 人机交互与抗闪烁策略
系统只有在频率、Vpp、Vrms和有效分量连续三帧满足稳定条件后才锁存新的显示快照。锁存后，参数文字和频谱仅重画一次；时域波形在用户按“启动”“一周期”或“三周期”时才显示或重画一次。这样既持续接收FPGA新帧，又不会因每帧清屏造成闪烁。串口屏断电重连时，STM32保留最后一份稳定快照并自动重放文字、频谱和已选波形，且不干扰FPGA测量链路。

5 测试方案、结果与分析

5.1 已完成的软件验证
已完成的主机合同测试覆盖SPI V1协议、CRC向量、非连续有效分量、DMA缓存约束、错误帧不ACK、DATA_READY时序、350点曲线生成、HMI按键命令、三帧稳定锁存和校准接口。工程现有测试记录为66项中61项通过；其中SPI V1/R2专项16项、HMI与校准专项18项均通过。其余失败项来自已退出正式运行链路的历史片内ADC/DDS/旧FFT模块，不能将它们作为当前FPGA-SPI主链路失败，也不能将主机测试等同于整机精度验证。

5.2 待完成的实测方案
应使用经校准的信号源和示波器/频率计作为参考，按10、20、50、100、150、200、300、400、450、500 kHz测试频率；在100 kHz下按0.1、0.2、0.5、1.0、1.5、2.0、2.5 Vpp测试幅值；再分别施加基波、基波+二次谐波、基波+二次+三次谐波，核对F1、F2、F3和频谱峰位置。固定100 kHz、1 Vpp连续运行10 min，每分钟记录一次频率、Vpp、Vrms和状态。每个测试点至少重复3次，记录均值、最大偏差和标准差。

6 误差分析

系统误差主要来自四部分：（1）模拟前端的增益误差、截止频率偏差、放大器非线性和噪声；（2）ADC参考电压、量化误差、采样时钟抖动和过载；（3）FFT栅栏效应、窗函数、频率分辨率及谐波靠近时的谱泄漏；（4）标量换算系数和显示压缩。对于正弦有效值，理论关系为Vrms=Vpp/(2√2)，非正弦信号必须采用采样点平方平均再开方，不能直接套用该公式。误差校准建议采用多点最小二乘拟合y=ax+b；若残差随频率呈系统性变化，可在不改变通信协议的前提下采用分段或低阶多项式校准。前端OPA847方案500 kHz处约0.8倍的实测现象说明，实际幅频响应必须优先于仅依据器件标称参数的推断。

7 结论

本设计建立了以FPGA为测量核心、STM32H743为可靠传输与显示控制核心的周期信号测量分析系统。采用抗混叠前端、帧级CRC与ACK、DMA缓存一致性处理、独立校准层以及稳定锁存显示策略后，系统在结构上具备测量、频谱分析、参数显示、触摸操作和故障可观测能力。软件合同验证支持协议与显示实现的正确性；下一阶段应完成前端幅频曲线、ADC满量程、20 MHz SPI联调、全频段幅频精度、谐波识别和10 min稳定性测试。获得这些实测数据后，即可将表1、前端元件值、关键电路图和波形截图补入，形成可提交的设计报告。

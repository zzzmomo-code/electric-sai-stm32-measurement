题目：周期信号测量分析装置

摘  要
为实现周期信号的频率、峰峰值、真有效值、频谱及主要谐波分量测量与直观显示，设计了一套由模拟调理、FPGA高速处理、STM32H743显示控制和串口触摸屏构成的测量分析装置。前端低通网络抑制带外干扰；FPGA完成高速采样、数字处理、FFT和参数提取；STM32H743以带帧序号、长度和CRC16校验的SPI接口读取完整测量快照，完成工程量换算、波形压缩和显示调度；串口屏显示数值、频谱以及一周期、三周期时域曲线。针对测量帧更新速度与串口屏绘图速度不匹配的问题，提出“完整快照锁存—短时标量平均—曲线冻结显示”的交互机制：启动键只锁存当前完整测量结果，不重新触发采样；其后仅在短时窗口内对小幅波动的文字量进行平均，曲线始终来自同一完整帧。该设计既避免波形闪烁和曲线、数值不同步，又保证按键响应不受重新计算过程限制。软件合同测试已覆盖协议校验、波形重采样、DMA传输和显示状态机；整机指标仍按测试方案进行实测验证。

关键词：周期信号测量；FPGA；STM32H743；FFT；SPI；串口触摸屏；测量快照

1 设计任务与要求

本装置面向周期信号的测量与分析。系统输入经抗混叠低通处理后送入高速采样链路，由FPGA获得时域样本、频谱以及频率、峰峰值、真有效值和谐波分量；STM32H743负责可靠读取、校准和显示；触摸屏提供启动、单周期、三周期和校准显示切换等操作。

正式定稿时，本节应逐条摘录题目原文中的测量频段、输入幅度、允许误差、响应时间及基本/发挥要求，并在第6节采用同一序号逐项给出测试结果。不得用“达到题目要求”等笼统表述替代指标和数据。

2 方案比较与论证

2.1 总体处理架构比较

方案一：由STM32直接完成采样、频谱分析、参数计算和屏幕显示。该方案器件数量较少，开发起点低，但高速采样、FFT运算、数据整理和串口绘图均集中在单一处理器中。当输入频率提高或需要同时显示时域、频谱与谐波参数时，计算与通信任务会相互争用，实时性和界面响应难以同时保证。

方案二：由FPGA完成采集和频谱分析，FPGA直接向串口屏输出绘图指令。该方案能够充分利用FPGA的并行处理能力，但把测量结果、屏幕分辨率、控件名称和串口协议耦合在同一逻辑中。调整界面、增加校准或更换屏幕时需要改动FPGA逻辑，调试边界不清晰，且难以实现可靠的按键交互和屏幕掉线恢复。

方案三：采用FPGA与STM32H743分层协同。FPGA只输出标准化的测量帧，STM32只接收物理量和数组，不接收“像素”；STM32再将数据映射为屏幕坐标并驱动串口屏。该方案将高速测量和人机交互分离：FPGA擅长实时并行计算，STM32擅长协议管理、DMA通信和界面状态控制。虽然增加了SPI帧协议和缓存管理工作，但可独立验证测量层、传输层和显示层，便于后续校准与功能扩展，因此选用方案三。

图1应绘制为：

被测周期信号 → 低通抗混叠滤波 → AD9226及采样时钟 → FPGA（采集、数字滤波、FFT、参数提取） → SPI + DATA_READY → STM32H743（完整性校验、校准、波形重采样、显示调度） → USART1 → 串口触摸屏。

2.2 测量数据传输方案比较

方案一：FPGA逐个字段或逐段发送数据，STM32收到后立即显示。其优点是协议短，但若帧传输过程中FPGA更新了结果，可能出现数值属于新测量窗、波形属于旧测量窗的情况；发生错误后也难以准确判断应丢弃哪一段数据。

方案二：FPGA发布一份不可修改的完整测量快照，STM32先读状态、再读全帧并校验，验证通过后发送确认帧。该方案采用“DATA_READY保持有效—读完整帧—CRC验证—正确ACK后释放”的闭环。状态帧和数据帧均包含长度、序号和CRC；校验失败时不ACK并有限次重读。该方案增加少量协议开销，却保证时域、频谱和标量参数来自同一测量时刻，故选用方案二。

为适应高频率大数据量传输，SPI使用Mode 0、8位MSB优先；多字节字段采用小端排列。STM32校验帧头魔数、版本、长度、保留字段、有效分量标志、帧序号和CRC-16/CCITT-FALSE。这样不仅能发现传输位错和数据损坏，也能将“协议不一致”和“测量结果无效”区分处理，为定位问题提供依据。

2.3 触摸屏显示方案比较

方案一：每得到一帧新数据就清空并重画全部曲线。该方法实现直接，但串口屏的绘图指令数量远多于参数文本。当FPGA帧速率快于屏幕绘图速度时，曲线会反复清空、绘制不完整或肉眼闪烁；用户按键还可能等待前一轮绘图结束，交互体验较差。

方案二：只显示数值，不显示时域和频谱曲线。该方案传输负担小，但无法让评委直观看到波形周期性、频谱峰值位置和谐波特征，缺少测量分析装置应有的可视化证据。

方案三：后台持续接收测量帧，前台仅显示一份“工作快照”。首份有效结果完成预装载后即可显示；用户按启动键时，STM32锁存当前完整帧，随后在最多800 ms的短窗口内，最多接纳两帧与已锁存结果小幅一致的新帧，对频率、幅值和有效分量等文字量取平均；如果变化超过阈值，立即结束本轮微调并保留已锁存结果。时域波形和频谱不参与平均，始终保持同一完整帧的350点缓存。该方案同时解决了显示闪烁、数值与波形不同步以及按键响应慢的问题，故选用方案三。

2.4 方案特点与创新点

（1）测量、传输和显示三层解耦。FPGA不生成屏幕命令，STM32不参与FFT主计算；两者以含单位和比例系数的测量帧连接。后续替换屏幕、调整坐标或加入校准时，不需要修改FPGA核心测量逻辑。

（2）以“完整快照”而非“连续字节流”作为显示数据的最小一致性单元。序号、长度、CRC和ACK使每次显示都可追溯到一份已验证的FPGA结果，避免显示模块读到半帧或跨帧混合数据。

（3）以“曲线冻结、标量微调”兼顾直观性与稳定性。曲线保留启动瞬间的相位、形状与频谱关系，文字量采用短时小幅平均降低读数抖动；两者的处理目标不同，避免用简单平均破坏波形形状。

（4）针对串口屏无逐点确认机制采用分批、双遍装载。350个显示点拆成32点小批次，经DMA依次发送；整条曲线发送两遍以降低上电忙或偶发解析丢指令造成的缺点。该策略在有限串口带宽下提高了显示成功率，而不是盲目提高发送速率。

3 理论分析与计算

3.1 抗混叠与采样参数分析

采样前必须抑制奈奎斯特频率以上的干扰。以50 MSPS总采样、四路复用的设计讨论为例，单通道等效采样率为12.5 MSPS，奈奎斯特频率为6.25 MHz。若12.6 MHz干扰没有在模拟前端被抑制，采样后可能以10 kHz的混叠分量出现，数字处理无法判断该分量是真实输入还是带外干扰。因此，低通抗混叠滤波器应布置在ADC之前。

本系统主要测量频段为500 kHz以下，前端截止频率暂定约1.3 MHz，以在500 kHz内尽量保持平坦响应，并对更高频率干扰提供衰减。截止频率和通带平坦度必须依据最终原理图的R、C实值及实测幅频曲线给出，不能仅凭设计目标写成已验证结论。

FPGA频谱计算采用4096点FFT，FFT采样率为1.5625 MSPS，频率分辨率为

Δf = fs / N = 1 562 500 / 4096 = 381.4697 Hz。

系统向STM32传送0～1311号频点，频谱幅值比例为10 μVpeak/LSB；时域数据采样率为12.5 MSPS，比例为10 μV/LSB。上述比例和采样率写入帧头，避免STM32依赖隐含常数解释FPGA数据。

3.2 时域曲线重构与显示时延分析

显示一周期时，STM32根据帧头的时域采样率和基频计算理论周期样点数：

Ns = fs,time / f0。

随后在时域缓存中搜索接近均值的上升穿越点，截取一个完整基波模板；显示三周期时将同一模板连续延拓三次。两个窗口均用Q16.16线性插值映射为350点。该方法不直接使用time_count/3，而是按测得基频确定周期边界，因而能避免缓存中恰好多于或少于三周期时产生的横轴失真。

完整测量帧长度为

L = 128 + 2×time_count + 2×spectrum_count + 2。

其中spectrum_count=1312，time_count为75～3750，故帧长为2904～10254字节。冻结协议目标时钟为20 MHz，最大帧的纯时钟传输时间约为4.10 ms；当前工程以625 kHz进行联调，最大帧传输约131 ms，二者不能混为一谈。串口屏每条曲线为350点，当前实现采用32点分批、每批间隔3 ms、整条两遍发送。该时间预算用于说明设计可行性，最终按键响应时间应以实物计时或逻辑分析仪测量为准。

4 系统软、硬件设计

4.1 模拟前端与FPGA测量单元

模拟前端由低通抗混叠滤波、ADC及其参考电压、采样时钟和供电去耦组成。低通网络限制带宽，ADC把模拟信号变换为数字样本，FPGA在同一测量窗内完成数字滤波、FFT、峰峰值、真有效值、基频和主要谐波分量计算。应在正式报告中给出前端关键原理图、ADC输入范围、参考电压、时钟来源、滤波器R/C实值和实测幅频曲线。

前期曾评估OPA847作20倍放大。器件资料显示其在闭环增益+20 V/V下针对平坦响应优化，最小稳定增益为+12 V/V；但实际电路中，电源去耦、走线寄生、源/负载阻抗和级间网络均会改变响应。原方案实测500 kHz处幅度约为10 kHz处的0.8，难以仅靠查表消除非线性，因而改用OPA690承担相应放大、滤波任务。这一过程说明器件选型既要参考手册，也必须以整机幅频实测为依据。

4.2 FPGA—STM32—串口屏接口及可靠显示设计

FPGA与STM32H743采用SPI3和一根DATA_READY握手线连接：PC10为SCK，PC11为MISO，PC12为MOSI，PA15为低有效片选FPGA_CS_N，PD1为FPGA_DATA_READY；接口逻辑为3.3 V且共地。串口屏连接USART1，PA9为TX、PA10为RX，通信参数为512000 baud、8N1。当前SPI3以625 kHz进行联调，协议目标为20 MHz，均采用Mode 0。

为避免H743带D-Cache时DMA读写陈旧数据，SPI和USART的大缓冲区均静态分配并按32字节对齐；DMA写入完成后使CPU缓存失效，DMA发送前将CPU写入内容清回内存。中断回调只记录“接收完成、发送完成或错误”等事件标志，帧解析、曲线构造和屏幕指令生成均在主循环中执行，避免在中断中进行耗时工作。

串口屏页面包括三个350点Waveform控件：s_t1显示一周期，s_t3显示三周期，s_spec显示频谱；s_t1与s_t3在相同位置重叠，s_spec独立放置。数值区显示Vpp、Vrms、基频、最多三个有效分量和通信状态。启动键发送A5 04 5A，一周期、三周期键分别发送A5 01 5A、A5 02 5A，校准切换键发送A5 20 5A。

页面加载与显示过程如下。第一份有效快照到达后，系统依次预装载数值、两条时域曲线和频谱；右侧频谱直接使用与文字区相同的最多三个独立频率分量，分量频率决定横坐标，分量峰值幅度按三者最大值归一化决定高度，1312点原始FFT数组仅保留作协议和饱和诊断。曲线在后台分批DMA发送，避免一次发送大量add命令使屏幕命令解析器过载。用户按“启动”后，系统不向FPGA发送重新测量命令，而是在当前串口小批次结束后复制最新完整快照，立即以该快照重装载曲线；启动帧计作第1帧，随后对满足小变化条件的标量数据进行平均，最多累计五帧。用户按“一周期”或“三周期”仅切换两个重叠控件的可见性，350点缓存不变，因此切换不需要重新采样、FFT或重传完整曲线。校准切换也只刷新文字，不清空频谱和时域曲线。

系统每秒发送一次页面查询命令检测屏幕在线状态。若屏幕断电或通信超时，STM32仍保留最新工作快照；检测到页面回复或有效按键后，自动重新发送初始化、文字和曲线，而不复位或暂停FPGA测量链路。该设计使显示器故障与核心测量过程相互隔离，提高了系统现场演示的可靠性。

4.3 软件流程

图2应绘制为如下主流程：上电初始化 → 等待DATA_READY → 读取状态帧 → 校验状态CRC、长度和序号 → DMA读取完整帧 → 校验帧头、版本、长度、有效标志和数据CRC → 合法则ACK并发布显示快照，非法则不ACK并限次重读 → 生成三组350点显示缓存 → 根据首帧、启动键、校准键或周期键选择一个显示动作 → USART DMA分批发送 → 处理发送完成、接收命令及掉线恢复。

CRC采用CRC-16/CCITT-FALSE：poly=0x1021，init=0xFFFF，无反射，xorout=0x0000；标准字符串“123456789”的校验值为0x29B1。状态帧、ACK帧和测量帧使用同一校验规则，降低双方实现不一致的概率。

5 测试方案与结果记录

5.1 测试仪器与条件

正式报告应列出信号发生器、示波器、频率计、数字万用表和逻辑分析仪的型号、量程和精度。每项测试都应注明输入频率、输入幅度、供电条件、校准状态和参考仪器，不同条件下的数据不能直接混合比较。

5.2 测试项目与方法

（1）通信与界面功能：上电检查参数、频谱和状态；分别按启动、一周期、三周期和校准键；断开再恢复屏幕和FPGA，观察状态提示与缓存恢复。

（2）频率与幅值：以经校准信号源在10、20、50、100、150、200、300、400、450、500 kHz逐点输入；在100 kHz下按0.1、0.2、0.5、1.0、1.5、2.0、2.5 Vpp输入。每点至少重复3次，记录均值、最大偏差和重复性。

（3）谐波与频谱：依次输入基波、基波加二次谐波、基波加二次及三次谐波，核对F1、F2、F3的频率、幅值和频谱峰位置。

（4）稳定性：固定100 kHz、1 Vpp输入连续运行10 min，每分钟记录频率、Vpp、Vrms、帧序号、错误计数和显示状态。

6 结果分析与结论

软件合同测试已覆盖SPI协议、CRC参考向量、帧格式、非连续有效分量、DMA缓存约束、错误帧不ACK、350点曲线生成、串口按键解析和显示状态机。该结果表明软件结构满足既定接口合同，但不能替代实物的精度、抗干扰和长期稳定性验证。

系统误差主要来自模拟前端通带起伏、ADC参考电压和量化误差、采样时钟抖动、FFT栅栏效应与谱泄漏，以及标量校准系数。对于正弦波，真有效值满足Vrms=Vpp/(2√2)；对非正弦周期信号，必须由样点平方平均后开方获得真有效值，不能直接套用正弦关系。建议采用多点最小二乘拟合y=ax+b建立频率和幅值校准；若残差随频率呈规律变化，再使用分段或低阶多项式拟合。

本设计的核心价值不只在于完成测量数据的传送，更在于保证“评委在屏幕上看到的一组数值、波形和频谱能追溯到同一份已校验测量快照”。通过FPGA—STM32分层、帧级可靠传输、短时标量微调、曲线冻结及屏幕重连恢复，系统兼顾高速测量、显示稳定和现场操作可靠性。待补齐前端幅频曲线、20 MHz SPI实测、全频段精度、谐波识别及10 min稳定性数据后，可据此完成最终指标结论。

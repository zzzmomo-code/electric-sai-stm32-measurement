# TJC4827T143_011R_I_P20 串口屏工程

源工程为 `hmi/ads8688_measure.HMI`。文件名沿用历史版本，当前显示数据来自 STM32H750 片上 ADC1/ADC2 双通道同步采样。

## 通信配置

- 页面名：`main`
- 分辨率：480 x 272
- USART1：9600、8N1、无校验、无流控
- MCU 使用阻塞轮询发送，不使用 USART1 DMA
- 不启用 USART1 global interrupt
- PA9/USART1_TX 接屏幕 RX，PA10/USART1_RX 当前不接，双方 GND 共地
- DMA1 Stream0 仅供片上双 ADC 采集使用，与串口屏无关
- 屏幕使用独立且能力足够的 5 V 电源

每条 TJC 命令末尾由 MCU 追加原始字节 `FF FF FF`。动态文本只使用 ASCII，所有动态 Text 控件的 `vscope` 均应设为全局。

## 最终动态控件

| 控件名 | 内容 | 示例 |
| --- | --- | --- |
| `t_amp` | CH1 峰峰值 | `1.000 Vpp` |
| `t_voltage` | CH1 完整分析帧平均电压 | `1.650 V` |
| `t_freq` | CH1 频率 | `1.000 kHz` |
| `t_wave` | CH1 波形 | `SINE` |
| `t_thd` | CH1 总谐波失真 | `0.10 %` |
| `t_status` | CH1 状态 | `LIVE` |
| `t_amp2` | CH2 峰峰值 | `0.800 Vpp` |
| `t_voltage2` | CH2 完整分析帧平均电压 | `1.649 V` |
| `t_freq2` | CH2 频率 | `1.000 kHz` |
| `t_wave2` | CH2 波形 | `SINE` |
| `t_thd2` | CH2 总谐波失真 | `0.12 %` |
| `t_status2` | CH2 状态 | `LIVE` |
| `t_phase` | CH2 相对 CH1 的相位差 | `14.0 deg` |

静态标签 `t0`、`t1` 等只负责页面文字，MCU 不向这些控件发送命令。建议所有动态控件的 `txt_maxl` 设为 20 或更大。

## 状态规则

- `WAIT`：该通道尚无有效测量结果。
- `LIVE`：该通道测量结果有效。
- `FAULT`：该通道发生削顶、信号过小或采集错误。
- 相位定义固定为 `CH2 - CH1`，仅在两通道频率和相位结果均有效时显示。
- 直流模式显示 `DC`；VPP、频率和 THD 显示 `--`。
- 平均电压由完整 8192 点分析帧的算术平均码转换为 `float`，不是最近一个 DMA 半缓冲区的瞬时均值。
- 前级未标定时，平均电压按标称 3.3 V 参考估算并显示为 `~1.650 V`，状态显示 `EST`；标定后去掉 `~`。

当前 13 条文本命令约每 500 ms 刷新一次。9600 波特率下不适合同时高频刷新完整频谱；64 点频谱接口保留为后续低频或分批发送功能。

## 烧录与验收

1. 在 USART HMI 中编译并将最新工程烧录到屏幕。
2. 在模拟器中逐条验证上述 13 个控件名，确认没有“变量名称无效”。
3. 烧录 MCU 固件并在实屏确认 CH1、CH2、相位和状态均能更新。
4. 改变任一通道输入，确认只改变对应通道数据；相位显示应随两路相位关系变化。
5. 每次修改页面后保存 `.HMI` 源工程，并重新生成、烧录对应的 TJC 编译文件。
